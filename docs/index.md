# 操作系统课程实验

复旦大学 **2026 年秋季学期《操作系统（H）》** 课程配套实验。

实验配套代码仓库：[OS-26Fall-FDU](https://github.com/rfieldsy/OS-26Fall-FDU)

## 整体实验目标

在 AArch64 多核平台上逐步构建能够运行 shell 的教学操作系统，理解内存、进程、设备与文件系统如何协作，掌握资源管理、隔离、并发与持久化的基本机制，形成系统设计与调试能力。

![教学操作系统整体架构：用户态、内核态及 QEMU 模拟硬件](/assets/os-architecture.svg)

## 贯穿实验的五个问题

随着实验推进，尝试结合自己的实现，逐步完善对以下问题的回答。

1. **操作系统如何把硬件资源转化为程序可用的抽象？** 进程、虚拟地址空间和文件分别屏蔽了哪些底层细节，又向程序提供了哪些保证？

2. **多个程序如何安全而高效地共享一台计算机？** 从资源的分配、隔离与回收出发，思考效率、公平性和保护之间的取舍。

3. **面对不可预测的执行顺序，内核如何保持正确并持续推进？** 思考共享状态应如何保护，以及等待与唤醒如何配合，才能避免竞态、死锁或无限等待。

4. **程序看到写入成功，是否意味着数据已经可靠保存？** 思考缓存、持久化与一致性的区别，以及更新中途发生故障时，系统应如何恢复。

5. **从输入一条 shell 命令到得到结果，操作系统经历了什么？** 尝试串起程序加载、调度、内存管理和 I/O，并思考如何沿这条路径定位问题。
